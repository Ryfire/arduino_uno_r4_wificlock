# DimmableR4Matrix

A patched fork of Arduino's **Arduino_LED_Matrix** driver for the UNO R4
WiFi/Minima's 12×8 LED matrix, adding whole-matrix software brightness
control while keeping full-brightness output identical to the original.

## Provenance

- **Upstream:** [Arduino_LED_Matrix](https://github.com/arduino/ArduinoCore-renesas/tree/main/libraries/Arduino_LED_Matrix) v1.1.0,
  distributed inside the `framework-arduinorenesas-uno` 1.5.1 board package
- **Upstream license:** MIT — © 2022-2023 Arduino SA (see [LICENSE](LICENSE))
- **This fork:** generated by [`tools/make_dimmable_matrix.py`](../../tools/make_dimmable_matrix.py) —
  regenerate rather than edit by hand, so the charlieplexing pin table stays
  byte-identical to the bundled library

## Changes vs upstream

1. Scan timer raised 10 kHz → 64 kHz (same LED duty cycle, 6.4× scan rate)
2. Whole-scan-cycle dimming gated by a Bresenham accumulator, exposed as
   `setBrightness()` / `getBrightness()` (0-100 %). The accumulator spreads
   the on-cycles evenly, keeping the pulse rate above the flicker-fusion
   threshold at every level instead of strobing.
3. Class renamed `ArduinoLEDMatrix` → `DimmableR4Matrix`; file-scope symbols
   prefixed `dr4m_` (no linkage collisions with the bundled library)
4. `gallery.h` include dropped — icon data the clock never uses; keeps this
   fork self-contained instead of leaning on the bundled library's copy

## Regenerating

```bash
python tools/make_dimmable_matrix.py
```

Requires the stock `framework-arduinorenesas-uno` package (the source of
truth) in your PlatformIO packages directory.
